# Sum of absolute values

Sum of absolute values

## Usage

``` r
dasum(N = NULL, X, INCX = 1L)
```

## Arguments

- N:

  Optional integer giving the number of elements. Defaults to
  \`length(X)\`.

- X:

  Double-precision vector, matrix or \[\`bigmemory::big.matrix\`\]
  input.

- INCX:

  Integer stride for traversing \`X\`.

## Value

Numeric scalar.
